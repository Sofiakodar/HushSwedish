# Security

If you find a security issue in **HushSwedish**, please **do not** open a public issue with exploit details.

**Report it privately:** on GitHub, open this repository → **Security** → **Report a vulnerability**. That uses [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/working-with-repository-security-advisories/configuring-private-vulnerability-reporting-for-a-repository) so maintainers can triage without disclosing the issue publicly.

For dependency and local-privacy notes, see [docs/dependencies.md](docs/dependencies.md) and [docs/local-privacy-audit.md](docs/local-privacy-audit.md).
